# The user is an expert agent user building the course, not the beginner it targets

The user already works daily across Claude Code, Codex and omp (three weeks of transcripts, hundreds of sessions), so lessons should not re-teach them the basics. They act as author and reviewer; the learner persona is a complete non-programmer. Their transcripts are the evidence base.

**Evidence**: Transcript inventory plus a deep read of 18 sessions; the user confirmed audience, mission, agent coverage, ordering (first-ship path with an early mini-deploy), plain-prompt (not skill-dependent) teaching, and approvals-on for beginners.

**Implications**: Review feedback from the author outranks my parametric knowledge of the tools. Where the author's practice (approvals off, personal skills, mature repo scaffolding) differs from what a beginner can do, the course teaches the beginner-safe version and notes the difference.
