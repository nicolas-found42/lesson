The agent loop

One page. Print it or keep it open while you work.

Chat vs agent

  • Chat: your message in, text out.
  • Agent: your message in, then many tool calls (read, edit, run), then a report.

The loop

  1. Gather context: read files, look around.
  2. Act: edit files, run commands.
  3. Verify: run or check the result. Repeat until the agent believes it is done.

Three tools, same loop

Remember

"Done" is a claim, not a proof. Look at the real result.
