Reference card

Failure modes

When a run goes wrong: find the stage, name the mechanism, apply the fix.

Rule zero

"Done" is a claim, not proof. Ask what the run actually showed you — and what it did not verify.

Read the Symptom column until one matches. The middle column is the usual misdiagnosis.
